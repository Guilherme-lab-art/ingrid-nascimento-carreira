# Materiais da Ingrid

Coloque nesta pasta os PDFs e arquivos que serão disponibilizados no site.

Antes de publicar:

- use nomes simples (ex.: `checklist-linkedin.pdf`);
- teste o arquivo no celular;
- não inclua dados de clientes sem autorização;
- atualize o link correspondente na seção “Materiais” do `index.html`.
