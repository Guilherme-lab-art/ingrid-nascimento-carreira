# Ingrid Nascimento — Carreira

Site institucional estático de Ingrid Nascimento, com foco em consultoria de carreira, posicionamento profissional e contato via WhatsApp.

## Publicação

O projeto é publicado via GitHub Pages a partir da branch `main`.

## Principais recursos

- Site mobile-first e responsivo
- Vídeo vertical 9:16 com pausa de 14 segundos antes de reiniciar
- Formulário que direciona a mensagem para o WhatsApp
- Links para e-mail e redes sociais
- Animações leves e respeito à preferência de movimento reduzido

Antes de uma divulgação definitiva, confirme as informações de formação presentes na seção “Sobre Ingrid”.
